# Design

this design is how this game is gonna be designed.

The game should:

- be a 2D game
- be played played in a browser
- support 2 players on the same keyboard

## Controls

Player 1:

- A - move left
- D - move right
- W - move aim upwards
- S - move aim downwards
- Left shift - jump
- Left ctrl - shoot

Player 2:

- Left arrow - move left
- Right arrow - move right
- Up arrow - move aim upwards
- Down arrow - move aim downwards
- Right shift - jump
- Right ctrl - shoot

## Characters

Pixelated person with health bar over the head.

## Weapons

- Hand gun (need 10 hits to kill person)
- Assult rifle (need 10 hits to kill person)
- Sniper rifle (1 hit for headshot, 3 hits for other parts)

## Game arena

Flat ground with a lot of random obsticles. It should be possible jump over the obsticles.

## Game play

The point of the game is to kill the other player.
