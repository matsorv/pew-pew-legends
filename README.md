# Pew Pew Legends

2D local multiplayer arena shooter. Two players share a keyboard and fight to eliminate each other.

**[Play now!](https://matsorv.github.io/pew-pew-legends/)**

## Controls

|  | Player 1 | Player 2 |
|---|---|---|
| Move | A / D | Left / Right |
| Aim | W / S | Up / Down |
| Jump | Left Shift | Right Shift |
| Shoot | Left Ctrl | Right Ctrl |
| Switch weapon | Q / E | , / . |

## Weapons

- **Handgun** — Medium fire rate, 10 hits to kill
- **Assault Rifle** — Fast auto-fire, 10 hits to kill
- **Sniper Rifle** — Slow with laser sight, 1 headshot or 3 body shots to kill

## How to run locally

```
npm install
npm run dev
```
